## Stroop Effect

This activity measures interference: reading a word can slow you down when the task is to name the ink colour. Time each list and record the difference.

Tick when tried: [ ]

Congruent or easy list: ______ seconds

Incongruent or colour-naming list: ______ seconds

Stroop cost: ______ seconds

Scoring: subtract the easy-list time from the colour-naming time. A larger positive number means more interference.

## Reaction Catch Challenge

This activity tests how divided attention affects fast responses. First catch normally, then repeat while doing the distraction task.

Tick when tried: [ ]

Normal attention: ______ caught out of ______

Divided attention: ______ caught out of ______

Attention cost: ______ fewer catches

Scoring: subtract the divided-attention score from the normal-attention score. A larger number means attention splitting had a bigger effect.

## Upside-Down or Prism Goggles

This activity shows how the brain adapts when vision and movement no longer match. Count how many attempts it takes before you hit the target cleanly.

Tick when tried: [ ]

Attempt 1 result: hit / miss

Attempts until first clear hit: ______

Final attempt result: hit / miss

Scoring: fewer attempts means faster adaptation. If you repeat the task, compare first-run attempts with second-run attempts.

## Buzz Wire Task

This activity tests hand-eye coordination, steady movement, and error correction. Move from one end of the wire to the other as accurately as possible.

Tick when tried: [ ]

Raw time: ______ seconds

Touches or buzzes: ______

Adjusted score: ______ seconds

Scoring: add 5 seconds for every touch or buzz. Adjusted score = raw time + (touches x 5). Lower is better.

## Tower of Hanoi

This activity tests planning: you need to move the stack while obeying the rules. Count every legal disk move.

Tick when tried: [ ]

Number of disks: ______

Moves used: ______

Minimum possible moves: ______

Solved? yes / no

Scoring: for 3 disks the minimum is 7 moves; for 4 disks it is 15; for 5 disks it is 31. Closer to the minimum means more efficient planning.

## Corsi Block-Tapping Task

This activity measures visuo-spatial working memory. Watch the block sequence, then repeat it in the same order.

Tick when tried: [ ]

Longest sequence repeated correctly: ______ blocks

First sequence length missed twice: ______ blocks

Scoring: your Corsi span is the longest sequence length you repeated correctly. Higher span means better short-term spatial memory for this task.
